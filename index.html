Your data

Everything you practise stays on this device: decks, settings, and the audio the dictation tab generates. Nothing is uploaded and there is no account. By default it is kept in this browser's storage. In Chrome or Edge you can choose a folder instead, so the files sit on disk where you can see, copy and back them up.

A backup is a zip laid out exactly like the folder. Unzip it anywhere and Chrome can open it as a data folder, or bring it back here with Restore.

Gemini API key

needed for dictation only

Dictation calls the Gemini API directly from this page with your key. It is stored in this browser's local storage, never in the data folder, so it cannot end up in a git commit, and it is sent to nobody but Google. Get one free at aistudio.google.com/apikey.

Spends one text-model call from today's budget.

Language

feeds the sentence prompt

Any language the model writes is fine; type its English name. Answer checking is language-agnostic: it compares accents and diacritics exactly, and aligns words with them stripped, which works the same for Vietnamese tones, Spanish acutes and German umlauts.

Models

Gemini model IDs

If a model ID is wrong the API's own error is shown verbatim, so a 404 here means exactly that.

Call budget

Counted in this browser before a request goes out, so you never discover the limit by being refused by Google. Windows roll over the last minute and the last 24 hours. 0 means unlimited. The defaults are Google's free tier.

Clears the local count. It does not reset Google's.

Prompts

exactly what gets sent

Placeholders: {language} {level} {languageNote} {terms} {minWords} {maxWords}. The reply is read back from the TARGET: and EN: lines, so keep those two labels; everything else is yours to rewrite.

Placeholder: {sentence}. Bare {sentence} just reads it out. A prefix such as Read slowly and clearly for a language learner: steers the delivery. The answer key stays the sentence alone, whatever you put here.

Read-aloud voice

Typing · built into this device

The voice that reads words aloud in Typing practice. These come with your operating system, cost nothing and work offline. Only voices for your target language are listed; to add more on a Mac, go to System Settings → Accessibility → Spoken Content → System voice → Manage Voices, then reload this page.

Dictation voices

One is drawn at random for each new sentence, so listening practice is not always the same speaker. Untick the ones you would rather not hear. You cannot untick them all, since something has to read the sentence.

Deck

the file, as it is stored

You can keep as many decks as you like, one file each; Typing and Dictation practise whichever deck is selected here. This is the deck file itself: a JSON array, one object per card. front is the word in the language you are learning, back is its meaning; notes is optional. score, recent and last_seen are written by the practice tabs, so you can leave them out of a card you type by hand and they will be filled in.
